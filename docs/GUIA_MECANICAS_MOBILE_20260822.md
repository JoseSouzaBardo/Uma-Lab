# Verificação em tela estreita — Guia de mecânicas

O guia foi verificado em viewport de 375 px. Os cartões de atributos, os blocos de pista e a tabela de estados passam para uma única coluna e permanecem em sequência legível, sem sobreposição observável.

Como nas verificações mobile anteriores, a captura integral do preview mostra área de fundo à direita; os conteúdos novos, porém, permanecem no fluxo vertical. Recomenda-se validação manual de toque no navegador local do usuário antes de uma coleta longa.
