# Exemplos para os sinais iniciais da build

| Sinal | Exemplo prático para a dica | Limite explícito |
|---|---|---|
| Stamina | Uma build pode entrar no último spurt com margem de HP apertada; recovery só ajuda quando a skill específica realmente ativa. | Não afirma que a build falhará nem estima colocação. |
| Consistência | Uma skill de posição ou ultrapassagem pode depender de uma situação que não ocorreu; Wit ajuda nos checks de skill, mas não cria a condição. | Não trata ausência de observação como falha. |
| Estratégia | Aptidão de estratégia abaixo de A reduz a eficácia mecânica de Wit; A é referência de aptidão, não uma nota de força da build. | Não compara estratégias como melhores ou piores isoladamente. |
